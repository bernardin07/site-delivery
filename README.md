# 🍔 Best Burger - Site de Delivery

Um site moderno e responsivo para hamburgueria com sistema de pedidos online.

## ✨ Características

- **Design Responsivo**: Funciona perfeitamente em desktop, tablet e mobile
- **Interface Moderna**: Design clean com cores vibrantes e animações suaves
- **Sistema de Pedidos**: Formulário interativo com cálculo automático de preços
- **Menu Dinâmico**: Cards de produtos com hover effects
- **Formulários Validados**: Validação em tempo real com feedback visual
- **Performance Otimizada**: CSS e JavaScript organizados e otimizados

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica e acessível
- **CSS3**: 
  - Flexbox e CSS Grid para layouts responsivos
  - Variáveis CSS para consistência de design
  - Animações e transições suaves
  - Backdrop filters para efeitos modernos
- **JavaScript**: 
  - Interatividade do menu mobile
  - Validação de formulários
  - Sistema de pedidos com cálculo automático
  - Máscaras de input para telefone

## 📱 Páginas

1. **Home** (`index.html`): Página inicial com hero section e navegação
2. **Menu** (`menu.html`): Cardápio com produtos e preços
3. **Quem Somos** (`quemsomos.html`): História e valores da empresa
4. **Contato** (`contato.html`): Formulário de contato e informações
5. **Cadastro** (`cadastro.html`): Registro de novos clientes
6. **Pedidos** (`pedidos.html`): Sistema completo de pedidos online

## 🔧 Funcionalidades

### Sistema de Pedidos
- Seleção de hambúrgueres com preços
- Acompanhamentos opcionais
- Cálculo automático do total
- Validação de dados de entrega
- Confirmação visual do pedido

### Design Responsivo
- Breakpoints: 768px (tablet) e 480px (mobile)
- Menu hamburger para dispositivos móveis
- Cards adaptáveis no cardápio
- Formulários otimizados para touch

### Validações
- Campos obrigatórios
- Validação de email
- Confirmação de senha
- Máscara para telefone
- Feedback visual de erros/sucesso
